# M5Stack ファームウェア

## 必要なパーツ

| パーツ | 数 | 備考 |
|---|---|---|
| FSR406 | 1 | 感圧センサ |
| M5Stack Basic | 1 | |
| 抵抗 10kΩ | 1 | プルダウン用。10MΩ だと軽く触れただけで値が振り切れ、ノイズも大きくなる |
| ジャンパーワイヤ | 3 | |
| ブレッドボード | 1 | |
| USB-C ケーブル | 1 | |

## 配線

```
3.3V ── FSR406 ──┬── G36（信号線）
                 │
               10kΩ
                 │
GND ─────────────┘
```

本体側面のピンヘッダーでは次の3本を使う:

| ヘッダー表記 | 接続先 |
|---|---|
| **AD**（2つ並んだ AD の下側 = G36） | FSR と 10kΩ の接続点（信号線） |
| **3V3** | FSR406 のもう片方の足 |
| **G** | 10kΩ のもう片方の足 |

- 2つ並んだ AD は上が G35、下が G36。シリアルモニタで FSR を押しても raw が変化しない場合は、もう一方の AD に挿し替えるか、`FSR_PIN` を 35 に変更する
- G2 と DA（G26）も ADC の表記があるが、ADC2 は無線使用中に読めないので使わない
- FSR406 に極性はない
- 電源は 3.3V（5V は不可）
- G36 は入力専用の ADC1 ピン。G35 を使う場合はコード上部の `FSR_PIN` を変更する

## 書き込み

1. Arduino IDE でボード **M5Core**（M5Stack ボードパッケージ）を選択し、「ツール」→「Partition Scheme」を **Huge APP (3MB No OTA/1MB SPIFFS)** にする（BLE が大きく、初期値の 1.2MB には入らない）
2. ライブラリマネージャで **M5Unified** と **ArduinoJson** をインストール（BLE はボードパッケージに含まれる）
3. `wakeup_alarm/wakeup_alarm.ino` を書き込み、シリアルモニタ（115200bps）で動作を確認
4. スマホのアプリを開くと BLE で自動的に接続し、M5Stack の時刻が合う（LCD の `BLE : connected`）

ボタン: **A(左) = 音量アップ / B(中) = 音量ダウン / C(右) = アラーム停止（ベッドの外にいるときだけ）**

## 設定値（`wakeup_alarm.ino` 上部）

| 定数 | 初期値 | 内容 |
|---|---|---|
| `IN_BED_THRESHOLD` | 300 | raw 値がこれ以上なら「ベッドにいる」。シリアルの raw 値を見て調整。アプリのデバイス画面からも変更できる（100〜3500） |
| `WAKE_CONFIRM_SEC` | 10 | 圧力なしがこの秒数続いたら起床（音はベッドを出た瞬間に止まる）。アプリのデバイス画面からも変更できる（5〜300秒） |
| `BED_WAIT_SEC` | 600 | アラーム時刻にベッドにいなければ、この時間内にベッドに入ったときに鳴らす |
| `SESSION_GAP_SEC` | 1200 | ベッドを出てこの時間内に戻れば、同じ睡眠が続いているとみなす（20分） |
| `SLEEP_START_CONFIRM_SEC` | 1200 | ベッドにいる状態がこの秒数続いたら睡眠開始（開始時刻はベッドに入った瞬間までさかのぼる） |
| `SENSOR_NOISE_SEC` | 10 | 在床中にこの秒数未満だけ圧力が消えても、センサーの誤差として連続扱い |
| `RESLEEP_WINDOW_SEC` | 1200 | 起床後この時間内にベッドへ戻ったら二度寝として扱う（`SESSION_GAP_SEC` と同じ） |
| `RESLEEP_DETECT_SEC` | 60 | 圧力ありがこの秒数続いたら二度寝（寝返りなどの誤検出防止） |
| `RESLEEP_ALARM_DELAY_SEC` | 300 | ベッドに戻ってから再アラームまで（5分） |
| `VOLUME_DEFAULT` | 1 | 起動時の音量（最小。ミュートではない） |
| `TIME_SYNC_GUARD_SEC` | 60 | アラーム時刻の前後この秒数は、スマホから届いた時刻を反映しない |
| `STATUS_NOTIFY_MS` | 1000 | 接続中に状態をスマホへ送る間隔 |

`IN_BED_THRESHOLD` と `WAKE_CONFIRM_SEC` は初期値。アプリから変更した値は NVS（Preferences）に保存され、電源を切っても残る。ベッドにいる間とアラーム中は変更できない（`locked`）。

- アラームはベッドにいる間だけ鳴る。ベッドを出た瞬間に音が止まり、10秒戻らなければ起床と判定する（戻ればまた鳴る）。時間の上限はない
- アラーム時刻にベッドにいなければ鳴らさず、10分以内にベッドに入ったらその時点から鳴らす。10分を過ぎたらそのアラームは終わり
- C ボタンはベッドの外で押すと、10秒待たずに起床と判定する
- ベッドにいる間は、アラームに関係なくスマホをロックする
- Wi-Fi は使わない。時刻はスマホから BLE で受け取る（接続時と4分ごと）。M5Stack Basic には RTC がないので、電源を入れ直したらスマホとつながるまで時刻は未設定（LCD に `time not set`）で、その間はアラームをセットできない
- 鳴動中・二度寝検出中・アラーム時刻の前後には時刻を動かさない
- 睡眠記録はアラームと関係なく、ベッドの在否だけで取る。ベッドに20分続けていたら（10秒未満の途切れは誤差として無視）ベッドに入った時刻から睡眠開始、20分以上ベッドを離れたら確定し、起床時刻は最後にベッドを出た時刻とする。アラーム後の二度寝（ベッドに戻った時刻）も送る。記録中の睡眠がないときに二度寝を検出したら、戻った時刻から記録を始める。記録の管理はアプリが行い、M5Stack は未送信のイベントを RAM に16件までためる

## 状態遷移

```
IDLE ─(アプリでセット)→ ARMED ─(時刻・ベッドにいる)→ RINGING
ARMED ─(時刻・ベッドにいない)→ WAITING ─(10分以内にベッドへ)→ RINGING
WAITING ─(10分経過)→ IDLE
RINGING ─(ベッドを出て10秒 / ベッドの外でボタンC)→ AWAKE [記録]
AWAKE ─(起床から20分以内にベッドへ戻り60秒)→ RESLEEP_ARMED ─(戻ってから5分)→ RINGING
RESLEEP_ARMED ─(鳴る前にベッドを出る)→ AWAKE
AWAKE ─(20分経過)→ IDLE / ARMED
ロック = ベッドにいる または RINGING / RESLEEP_ARMED
```

## BLE

| 項目 | UUID | 内容 |
|---|---|---|
| サービス | `6e0f0001-3b6a-4c1e-9b3a-2a4f8c1d7e01` | 広告名 `WakeUp` |
| 状態 | `6e0f0002-…` | read / notify。状態の JSON（1秒ごと、コマンド処理後にも送る） |
| コマンド | `6e0f0003-…` | write。コマンドの JSON |

コマンド:

| JSON | 内容 |
|---|---|
| `{"cmd":"time","epoch":<UNIX秒>}` | 時刻を合わせる |
| `{"seq":n,"cmd":"set","epoch":<UNIX秒>}` | アラームをセット |
| `{"seq":n,"cmd":"cancel"}` | アラームを解除 |
| `{"cmd":"evack","id":n}` | 睡眠イベント n を受け取った。M5Stack は次のイベントを `e` で送る（最大16件ためておける） |
| `{"seq":n,"cmd":"config","th":<raw>,"wc":<秒>}` | 在床しきい値と起床確認時間を変更（範囲外は `out of range`、在床中・アラーム中は `locked`） |

`seq` を付けたコマンドの結果は、状態の `k` に入る（error が空なら成功。`locked` / `time not set` など）。

状態は notify 1回（MTU 247 なら 244 バイト）に収まるよう、短いキーにしている:

```json
{"s":"AWAKE","l":0,"a":0,"v":1,"t":1761300000,"r":12,"b":0,"w":[1,1761299900,1761299942,42,0],"e":[3,"E",1761300003],"k":[123,""],"c":[300,10]}
```

| キー | 内容 |
|---|---|
| `s` | 状態（IDLE / ARMED / WAITING / RINGING / AWAKE / RESLEEP_ARMED） |
| `l` | スマホをロックするか（1/0） |
| `a` | 次に鳴る時刻（WAITING のときは待ちの期限） |
| `v` / `t` / `r` / `b` | 音量 / 現在時刻 / FSR の raw / ベッドにいるか |
| `w` | 最後の起床記録 `[id, ringAt, awakeAt, durationSec, resleep]`。なければ null |
| `e` | 未送信でいちばん古い睡眠イベント `[id, 種類, 時刻]`。種類は S=就寝（ベッドに入った時刻）/ R=二度寝（ベッドに戻った時刻）/ E=起床（最後にベッドを出た時刻）。なければ null |
| `k` | コマンドの結果 `[seq, error]` |
| `c` | 現在の設定 `[在床しきい値, 起床確認秒]` |
